# 第一部分：产品 PRD（商务规范版）

## 1. 产品基本信息
- **产品名称**：AI 求职智能管家
- **产品版本**：V1.0
- **产品定位**：面向求职者的企业级 AI 多智能体求职辅助工具
- **核心价值**：安全合规投递、AI 精准优化简历、全流程可控、隐私本地存储
- **目标用户**：职场求职者、技术/产品/运营岗求职人群
- **交互模式**：PC 端网页 / 客户端界面，商务简约风格
- **合规原则**：人工必确认、行为真人化、数据本地化、责任清晰化

## 2. 核心业务流程（标准主线）
1. 启动工具 → 登录平台（BOSS 直聘）
2. 上传简历 → 系统自动解析
3. 输入 JD / 岗位链接 → AI 匹配打分
4. 生成优化简历与优化建议
5. 人工确认投递 → 自动填充表单
6. 完成投递 → 记录投递日志
7. 查看投递统计与进度

## 3. 功能模块 PRD 明细

### 3.1 工作台（首页）
- 展示今日可投递额度、今日已投递数、匹配度统计
- 快捷入口：上传简历、新建投递任务、查看投递记录
- 风险提示区：账号状态、风控提示

### 3.2 简历管理
- 简历上传（PDF/DOCX）
- 简历解析结果预览
- 原始简历 / 优化简历版本管理
- 简历导出、删除、加密存储

### 3.3 JD 解析与岗位匹配
- JD 文本输入 / 岗位链接输入
- 自动提取岗位要求：技能、年限、学历、关键词
- 简历匹配度打分（0–100）
- 匹配差异项展示（缺什么、弱什么）

### 3.4 AI 简历优化
- 一键生成优化版简历
- 优化建议清单（修改前后对比）
- 求职信生成
- 简历复制 / 导出

### 3.5 自动化投递任务
- 任务列表：岗位、公司、匹配分、状态
- 投递前二次确认
- 投递进度实时展示
- 异常处理弹窗（验证码、登录失效）

### 3.6 投递记录与数据看板
- 历史投递列表：公司、岗位、时间、匹配分、状态
- 筛选：时间、状态、平台
- 日/周统计图表
- 导出 Excel

### 3.7 系统设置
- 账号与登录管理
- 投递风控设置（每日上限、延时、投递时段）
- 大模型 API 配置
- 数据清理、隐私设置
- 用户协议与免责声明

### 3.8 异常与风控交互
- 验证码弹出 → 页面遮罩 + 输入框
- 登录失效 → 引导重新登录
- 页面改版 → 自动停止并提示
- 当日达上限 → 锁定投递按钮

## 4. 交互规则（商务规范）
1. 所有高危操作必须二次确认
2. 投递行为**必须人工确认**，不可全自动
3. 异常状态统一顶部提示条
4. 加载状态使用骨架屏，禁止无反馈
5. 表格数据支持排序、筛选、导出
6. 所有页面保持统一导航结构

## 5. 合规与免责（必须展示）
- 本工具仅为个人求职辅助，不代表平台官方
- 用户需遵守招聘平台用户协议，账号风险自行承担
- 数据仅本地存储，不上传云端
- 因页面改版、平台策略导致功能失效属正常现象

# 第二部分：前端 UI 设计规范（商务正式风格）

## 1. 整体视觉规范
### 1.1 色彩系统
- **主色**：商务蓝 `#165DFF`（按钮、重点高亮、导航）
- **辅助色**：
  - 成功绿 `#00B42A`
  - 警告橙 `#FF7D00`
  - 危险红 `#F53F3F`
  - 信息灰 `#86909C`
- **中性色**：
  - 背景 `#F5F7FA`
  - 卡片 `#FFFFFF`
  - 边框 `#E5E6EB`
  - 文字一级 `#1D2129`
  - 文字二级 `#4E5969`
  - 文字三级 `#86909C`

### 1.2 字体
- 中文：`Microsoft YaHei / PingFang SC`
- 数字/英文：`Inter`
- 标题：18px / 20px / 24px
- 正文：14px
- 辅助文字：12px
- 按钮文字：14px 中等加粗

### 1.3 布局规范
- 页面宽度：1200px 居中
- 卡片间距：24px
- 内边距：16px / 20px / 24px
- 圆角：4px–6px（商务极简，不使用大圆角）
- 阴影：轻量卡片阴影 `0 2px 8px rgba(0,0,0,0.06)`

### 1.4 图标与控件
- 图标使用线性图标，风格统一
- 按钮：
  - 主按钮：蓝底白字
  - 次按钮：灰边白底
  - 文字按钮：无背景
- 表格：隔行变色，表头固定，hover 高亮

# 第三部分：页面结构与 UI 布局设计（共 8 个核心页面）

## 页面1：登录 / 平台绑定页
**商务简洁版布局**
- 顶部：产品 Logo + 产品名称「AI求职智能管家」
- 中间卡片（600×400）：
  - 标题：选择招聘平台
  - 平台图标：BOSS 直聘（优先支持）
  - 登录方式：扫码登录
  - 提示文字：仅本地保存登录状态，保障账号安全
- 底部：用户协议 + 隐私声明 链接

**UI 风格**：居中卡片式，极简商务，无多余装饰

## 页面2：工作台（首页 Dashboard）
**布局：上导航 + 左侧边栏 + 右内容区**
- 顶部导航：产品名、账号状态、系统设置、帮助
- 左侧菜单：工作台、简历管理、岗位匹配、简历优化、投递任务、投递记录、设置
- 内容区：
  1. **数据概览卡片行（4列）**
     - 今日可投递
     - 今日已投递
     - 平均匹配分
     - 账号正常状态
  2. **快捷操作区**
     - 上传简历
     - 新建投递任务
     - 查看全部记录
  3. **最近投递记录（表格）**
  4. **风险提示条**

## 页面3：简历管理页
- 顶部：标题 + 上传简历按钮
- 列表卡片布局：
  - 简历名称、类型、上传时间
  - 操作：解析、预览、优化、导出、删除
- 解析结果抽屉：
  - 个人信息、技能标签、工作经历、项目经历结构化展示

## 页面4：JD 解析 & 岗位匹配页
- 左侧输入区：
  - 选择简历
  - 输入 JD 文本 / 岗位链接
  - 开始匹配按钮
- 右侧结果区：
  - 匹配度分数环（商务图表）
  - JD 核心要求（技能、年限、学历标签）
  - 匹配差异：匹配项 / 缺失项
  - 按钮：去优化简历

## 页面5：AI 简历优化页
- 顶部：匹配岗位信息 + 匹配分数
- 双栏对比布局：
  - 左：原始简历片段
  - 右：AI 优化后简历
- 优化建议列表（卡片式）：
  - 每条建议带：优化点、原因、示例
- 操作区：
  - 复制优化简历
  - 导出简历
  - 生成求职信
  - 进入投递

## 页面6：投递任务执行页
- 任务信息卡片：
  - 公司、岗位、薪资、匹配分
- 投递控制区：
  - 投递倒计时/延时设置
  - 确认投递按钮（主按钮）
- 浏览器状态实时展示：
  - 正在打开页面 → 已识别表单 → 已填充信息
- 异常处理区：
  - 验证码弹出时：显示截图 + 输入框 + 提交

## 页面7：投递记录 & 数据统计
- 顶部：筛选器（时间、状态、平台）+ 导出按钮
- 表格列：
  - 序号、公司、岗位、匹配分、投递时间、状态、操作
- 底部：简单统计图表
  - 近7日投递量趋势图
  - 匹配分分布

## 页面8：系统设置页
商务左右分栏：
- 左侧菜单：
  - 账号设置
  - 投递风控设置
  - API 模型设置
  - 数据与隐私
  - 关于与协议
- 右侧内容区：
  - 每日最大投递量输入框
  - 投递延时滑块
  - 投递时段选择
  - 清理本地数据按钮
  - 用户协议文本展示

# 第四部分：组件规范（可直接给前端开发）
## 1. 按钮规范
- 高度：36px / 40px
- 主按钮：`#165DFF` 圆角 4px
- 禁用态：透明度 0.5 不可点
- 文字按钮：无边框，文字色 `#165DFF`

## 2. 表单规范
- 输入框高度：36px
- 边框：`#E5E6EB`
- 聚焦：蓝色边框 1px
- 提示文字：12px 灰色

## 3. 表格规范
- 表头背景：`#F7F8FA`
- 行高：48px
- 边框：下边框 1px `#E5E6EB`
- 操作列固定右侧

## 4. 弹窗与抽屉
- 弹窗宽度：600px / 800px
- 抽屉：右侧滑出，宽度 400px
- 底部固定按钮栏

## 5. 状态标签规范
- 匹配成功：85+ 绿
- 一般匹配：60–84 橙
- 低匹配：<60 灰
- 投递状态：
  - 待确认：蓝
  - 已投递：绿
  - 异常：红
  - 已取消：灰
