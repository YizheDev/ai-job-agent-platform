# AI求职多智能体助手（AI Job Agent）
## 需求规格设计文档 V1.0
**适用阶段**：项目立项、开发实施、环境搭建、团队协作
**文档用途**：开发人员上手依据、需求基准、验收标准
**技术栈基线**：Anaconda3 + Python 3.11 + LangGraph + Playwright/browser-use

---

# 1. 文档概述
## 1.1 文档目的
本文档为**AI求职多智能体自动化工具**的完整需求设计说明，明确产品功能、非功能要求、业务流程、风险控制、多智能体架构及开发规范，用于指导开发、测试、部署及项目维护。

## 1.2 范围
覆盖：简历解析、JD智能匹配、AI简历优化、浏览器自动化投递、风控限流、异常处理、验证码/登录失效处理、本地隐私存储、投递进度管理。
不含：商业代投、批量恶意投递、云端存储用户隐私、跨平台商业分发。

## 1.3 术语定义
- **Agent**：智能体，承担单一专业职责的执行单元
- **LangGraph**：多智能体流程编排框架
- **JD**：岗位描述（Job Description）
- **MVP**：最小可用版本
- **风控**：平台行为检测与账号安全保护
- **browser-use**：AI驱动浏览器自动化工具

# 2. 项目背景与目标
## 2.1 背景
1. 求职者手动投递简历效率低、简历与JD匹配度低
2. 开源投递脚本无风控、易封号、无优化、无异常处理
3. 无本地化、可控、安全的AI求职辅助工具
4. 多智能体可实现分工协作，完成复杂求职全流程自动化

## 2.2 项目目标
1. 实现**JD-简历智能匹配**，提升简历通过率
2. 实现**AI针对性简历优化**，贴合岗位关键词
3. 实现**合规半自动投递**，模拟真人行为，避免封号
4. 完善异常处理：验证码、登录失效、页面改版、风控拦截
5. 数据本地化存储，杜绝简历泄露与隐私风险
6. 企业级架构，可维护、可扩展、可协作开发

# 3. 产品定位
## 3.1 核心定位
**个人级AI求职管家**
基于多智能体的合规求职辅助工具，提供「简历解析→JD匹配→智能优化→安全投递→进度跟踪」一站式服务。

## 3.2 差异化优势
1. **风控优先，不封号**：真人行为模拟、限流、时段控制
2. **AI优化而非暴力投递**：提升面试率而非仅投递量
3. **全流程可控**：人工确认机制，防止误投
4. **隐私本地化**：不上传云端，本地加密存储
5. **异常自愈**：验证码暂停、登录重连、页面改版降级
6. **企业级架构**：基于LangGraph，稳定可维护

## 3.3 Slogan
AI求职管家：安全不封号，精准拿面试

# 4. 目标用户与使用场景
## 4.1 目标用户
- 互联网/IT行业求职者（后端/前端/测试/产品/运营）
- 追求效率、希望优化简历的职场人
- 担心脚本封号、隐私泄露的用户
- 开发人员自用/小范围使用

## 4.2 核心使用场景
1. 上传个人简历，粘贴岗位JD，快速获取匹配度与优化建议
2. 批量岗位筛选，AI自动优化简历，半自动完成投递
3. 投递过程遇到验证码/登录失效，工具自动暂停等待人工介入
4. 查看投递历史、匹配分数、岗位状态，形成求职复盘
5. 平台页面改版，工具自动降级为手动投递兜底

# 5. 功能需求（模块化设计）
## 5.1 简历管理模块
1. **简历上传**
   - 支持 PDF / DOCX 格式
   - 单文件大小 ≤ 10MB
2. **简历解析**
   - 自动提取结构化信息：个人信息、技能、工作经历、项目、学历
3. **简历版本管理**
   - 保存原始简历 + 多份AI优化版本
   - 支持预览、编辑、导出
4. **本地存储**
   - 简历仅存储在本地，不上传云端

## 5.2 JD解析与岗位匹配模块
1. **JD输入**
   - 支持手动粘贴JD文本
   - 支持岗位URL解析（V1.1）
2. **JD结构化提取**
   - 岗位名称、要求技能、工作年限、学历、关键词
3. **智能匹配**
   - 关键词匹配 + 语义匹配
   - 输出 0~100 匹配分数
   - 列出缺失/薄弱项
4. **过滤规则**
   - 支持自定义匹配阈值（默认70分）
   - 低于阈值不进入投递流程

## 5.3 AI简历优化模块
1. **智能优化**
   - 基于JD自动插入高频关键词
   - 量化工作成果，优化表述
2. **优化建议**
   - 输出至少3条可执行优化点
   - 提供修改前后对比
3. **求职信生成**
   - 生成对应岗位的简短求职信
4. **行业适配**
   - 支持互联网技术/产品/运营等岗位风格

## 5.4 自动化投递模块
1. **平台支持**
   - 首期支持 BOSS直聘
   - 后续扩展智联、猎聘
2. **投递模式**
   - 半自动模式（默认强制）：自动填表，人工确认提交
   - 禁止全自动无确认投递
3. **表单自动填充**
   - 姓名、电话、经历、技能自动填充
   - 自动上传对应优化简历
4. **投递控制**
   - 批量任务列表确认
   - 支持中途取消

## 5.5 风控与限流模块
1. **投递频率控制**
   - 单日单平台最大投递量 ≤ 20
   - 投递间隔 2~4秒随机延时
   - 仅允许 9:00~18:00 投递
2. **行为模拟**
   - 随机鼠标轨迹、停留、滚动模拟
3. **风控检测**
   - 自动识别“账号异常”“操作频繁”等页面关键词
   - 触发风控立即暂停，给出人工处理指引

## 5.6 异常处理模块
1. **验证码处理**
   - 滑块/图文/短信验证码自动暂停
   - 页面截图展示，用户输入后继续
2. **登录失效处理**
   - 自动检测登录过期
   - 引导重新扫码登录
   - 登录后断点续投
3. **页面改版处理**
   - 元素匹配失败自动识别
   - 暂停并提示页面结构变化
   - 提供手动投递兜底入口
4. **异常日志**
   - 本地记录异常类型、时间、截图

## 5.7 投递进度与统计模块
1. **投递记录**
   - 公司、岗位、链接、匹配分、时间、状态
2. **状态标记**
   - 待投递/投递成功/误投/已撤回/无反馈
3. **数据统计**
   - 日/周投递量
   - 平均匹配分数
4. **数据导出**
   - 导出 Excel 报表

## 5.8 系统设置模块
1. **隐私设置**
   - 本地数据加密
   - 一键清空所有数据
2. **风控参数自定义**
   - 自定义日投递上限
   - 自定义投递延时
3. **模型配置**
   - 支持切换大模型API
4. **关于与协议**
   - 展示用户责任界定协议
   - 展示风险提示

# 6. 非功能需求
## 6.1 性能需求
- 简历解析 ≤ 3s
- JD解析+匹配 ≤ 5s
- 简历优化 ≤ 10s
- 单岗位投递流程 ≤ 60s（含人工确认）

## 6.2 安全与隐私需求
- 所有简历、Cookie、账号状态**仅本地存储**
- 配置文件加密存储
- 不上传任何隐私数据至第三方服务器
- 支持一键数据销毁

## 6.3 合规需求
- 仅模拟人工正常求职行为
- 不爬取非公开数据
- 不恶意批量投递
- 明确责任：用户自行承担平台账号使用风险

## 6.4 兼容性
- Windows 10+/macOS 12+
- Anaconda3 + Python 3.11
- Chrome 最新版

## 6.5 易用性
- 操作步骤 ≤ 3步完成核心流程
- 异常提示清晰易懂
- 无需编程基础即可使用

# 7. 多智能体架构设计（基于LangGraph）
## 7.1 整体架构
1. **Main 主控层**：项目入口、流程启动
2. **Workflow 编排层**：LangGraph 状态机、流程控制
3. **Agent 智能体层**：业务执行单元
4. **Tool 工具层**：浏览器、解析、加密、存储
5. **Storage 存储层**：本地SQLite/文件

## 7.2 智能体职责
| 智能体 | 职责 |
|--------|------|
| ResumeAgent | 简历上传、解析、结构化 |
| JDMatchAgent | JD解析、关键词提取、匹配打分 |
| OptimizeAgent | AI简历优化、建议生成 |
| DeliveryAgent | 浏览器自动化、表单填充 |
| RiskControlAgent | 限流、行为模拟、风控检测 |
| ExceptionAgent | 验证码、登录失效、页面改版处理 |
| ProgressAgent | 投递记录、统计、导出 |

## 7.3 框架依赖
- 流程编排：LangGraph
- 浏览器自动化：Playwright + browser-use
- 简历解析：pyresume
- 大模型：通用LLM API
- 环境：Anaconda3 + Python3.11

# 8. 核心业务流程
## 8.1 标准求职流程
```
上传简历 → 粘贴JD → 解析匹配 → AI优化 → 人工确认 → 半自动投递 → 记录进度
```

## 8.2 异常分支流程
1. 匹配度过低 → 终止投递
2. 触发风控 → 暂停并提示
3. 出现验证码 → 暂停→用户输入→继续
4. 登录失效 → 重登→断点续投
5. 页面改版 → 终止自动→引导手动投递

# 9. 风险防控与责任界定
## 9.1 账号风险处理
- 工具仅提供操作模拟，不保证平台不触发风控
- 内置限流降低风险，不承诺100%不封号
- 提供账号异常申诉指引

## 9.2 隐私风险处理
- 数据本地存储，无云端上传
- 明确不承担用户主动泄露信息导致的问题

## 9.3 误投责任
- 强制人工确认机制
- 工具不承担误投、错投、投递到不合规公司责任

## 9.4 页面改版
- 平台页面变化导致脚本失效属于正常现象
- 工具提供兜底方案，不承担无法自动投递问题

## 9.5 强制用户协议要点
1. 本工具仅个人合法求职使用
2. 用户需遵守招聘平台用户协议
3. 账号安全、封禁风险由用户自行承担
4. 禁止用于商业代投、恶意投递
5. 简历隐私由用户自行保管
